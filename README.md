# Protocolo XABCDE - Aplicação Desktop

Aplicação desktop para gerenciamento e execução do protocolo XABCDE, com sistema de alertas e sugestões de correção.

## Requisitos do Sistema

- Python 3.9 ou superior
- Conexão com Internet (para sincronização com Firebase)
- Windows 10/11

## Instalação

1. Clone o repositório:
```bash
git clone [seu-repositorio]
cd protocolXABCDE
```

2. Crie um ambiente virtual:
```bash
python -m venv venv
.\venv\Scripts\activate
```

3. Instale as dependências:
```bash
pip install -r requirements.txt
```

4. Configure as variáveis de ambiente:
- Crie um arquivo `.env` na raiz do projeto
- Adicione suas credenciais do Firebase

## Funcionalidades

- Interface gráfica intuitiva
- Sistema de alertas em tempo real
- Base de dados de causas e soluções
- Histórico de casos
- Sistema de busca avançada
- Exportação de relatórios
- Backup automático
- Modo offline

## Uso

1. Ative o ambiente virtual:
```bash
.\venv\Scripts\activate
```

2. Execute a aplicação:
```bash
python main.py
```
